# ROOT Live-to-Clean Parity Matrix

## Reference Findings

The current live ROOT public gateway includes the Mirror Law, privacy positioning, a consent receipt concept, a proof ledger concept, services, Truth Talk entry, member sign-in, and public provenance feed framing. The live Project Reclaim page includes six pillars, voluntary and no-score safeguards, private member-interest language, two reviewed Mendocino sources, and an explicit Lake County watchlist-only boundary.

## Current Comparison

| Capability | Live ROOT | Clean restart | Required before replacement |
|---|---|---|---|
| Public gateway and Mirror Law | Present | Present | Add the live control-surface elements: proof ledger, services, and consent-receipt framing. |
| Authentication | Manus sign-in present | Local preview only | Add managed OAuth in a new full-stack project. |
| Member record and permissions | Persistent private data and receipts | UI preview only | Add durable storage, protected routes, grant/revocation records, and export. |
| Truth Talk | Separate `/truth` entry and provenance feed | Not yet in clean restart | Add the linked Truth Talk handoff and public feed boundary. |
| Project Reclaim | Six pillars, member-interest ledger, issuer sources/audits | Two public sources, private pathway preview, steward boundary | Add persistent pathways, source issues, source lifecycle, review audit, and all six pillars. |
| Issuer workspace | Active First Executive, operator intake, Monarch nodes, source controls | Steward boundary preview | Add protected First Executive/Directory Steward workflows and audit records. |
| Emergency boundary | One-time consent and non-persistent location design | Not yet in clean restart | Add one-time-only consent flow without location history. |
| Ecosystem handoffs | Existing connected public ecosystem | Link-only handoffs | Retain link-only mode until a member issues a field-specific consent grant. |

## Conclusion

The clean restart has the visual and policy core, but it is **not yet equivalent** to the live ROOT application. It must gain managed OAuth, persistent data, server-side authorization, the broader member/issuer workflow, Truth Talk handoff, and the established Project Reclaim audit model before it can be a verified replacement.
