# ROOT Ecosystem Connection Registry — v0.1

**Status:** Reviewed registry of public links and supplied instances. This registry establishes no trust, node enrollment, shared account, private-data transfer, health claim, or automatic synchronization.

ROOT records the supplied ecosystem surfaces so that connection work can be explicit rather than assumed. Each known public application may be opened through a link-only handoff. Each instance without an approved canonical HTTPS origin is held as `endpoint_pending`; it is not contacted by ROOT and has no ROOT member-data access.

Before any instance advances beyond this registry, its owner must supply a canonical HTTPS origin, deployment ownership evidence, a data and telemetry map, a signed public manifest, signing-key and revocation procedures, a declared processing region, and explicit member-consent UX. A network address alone is never sufficient to establish trust.
